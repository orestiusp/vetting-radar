BENCHMARKING & MONITORING
SIRE 2.0
INTERTANKO, through the work of its Vetting Committee, has developed a SIRE 2.0 benchmarking tool.
You can view a User Guide, here.
The system allows Members to compare their SIRE 2.0 number of observations (negative and positive) for each chapter, as well as the total number of observations against a pool of other INTERTANKO users. This allows users to benchmark their observations, both overall and by chapter, against the INTERTANKO average.
The SIRE 2.0 application features a user-friendly interface, allowing Members to upload a Json file containing the SIRE 2.0 report downloaded from the OCIMF website on a vessel-by-vessel basis, ensuring the most accurate benchmarking.
Filters allow users to benchmark core questions and compare the same types of ships based on size, age range, and other criteria. These filtering options enable a more detailed analysis, helping users gain deeper insights into specific performance aspects.
